# Distill Source

拆资料，不替用户读完。输出是学习入口，不是终稿讲义。

## 何时用

用户给出一本书、一篇文档、一门课或一组链接，并希望建立结构、划重点、稍后自学或验收。

## 产出

优先写入当前 `sessions/<date>-<topic>/`；来源元数据同时可写入 `knowledge/<topic>/sources.md`（用 `templates/source.md`）。

至少给出：

1. 来源信息（标题、作者、范围、建议阅读切面）
2. 该来源覆盖的知识地图
3. Core / Important / Optional
4. 与当前学习目标的关系（相关 / 超出 / 缺前置）
5. 用户自学时应回答的问题（问句，不写完整答案）

## 规则

- 先问清：整本拆还是只拆当前目标需要的章节。
- 默认按当前学习目标裁剪，不把整本书摊成无限大纲。
- 不要生成可直接背诵的超长摘要来代替阅读。
- 发现资料本身含混或冲突时，标成待验证，不要圆成确定结论。
- 拆完后回到 `study-session`：更新 `plan.md`，然后让用户自己学。
