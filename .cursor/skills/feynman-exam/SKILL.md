# Feynman Exam

验收 skill。先读当前会话的 `plan.md` 和 `AGENTS.md` 中的验收规则。

## 步骤

1. 提醒用户不看原资料。
2. 用 Examiner 口吻，让用户按学习目标连续讲解 Core 项。先听完，再追问。
3. 切到 Novice：完全不懂该主题、但有正常逻辑。只根据用户刚说的内容问下一问。
4. 优先追模糊词、假因果、只复述定义、以及「自动 / 保证 / 一定」这类断言。
5. 连续若干轮没有新的 Core 漏洞后结束。不要为了提问而提问。
6. 用 `templates/exam.md` 写 `sessions/<date>-<topic>/exam.md`。
7. 有明显漏洞：指出缺口类型（定义 / 因果 / 机制 / 边界 / 应用），只补这一块，然后必须再验收一次。

## 禁止

- 「你明白了吗？」
- 用户说懂了就判掌握
- 用选择题代替讲解验收
- 把 Optional 细节当成不过关理由
- 讲完标准答案后立刻宣布 L3/L4

掌握等级只看当场表现。只会背定义，最高 L1。
