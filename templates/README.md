# templates/

Agent 写学习产物时先复制对应模板，再填内容。不要另起标题结构。

| 模板 | 用到哪里 |
| --- | --- |
| `plan.md` | `sessions/<date>-<topic>/plan.md` |
| `exam.md` | `sessions/<date>-<topic>/exam.md` |
| `note.md` | `knowledge/<topic>/notes.md` |
| `card.md` | `knowledge/<topic>/cards.md` 中的单卡 |
| `source.md` | `knowledge/<topic>/sources.md` 中的单条来源 |
| `review-log.md` | `knowledge/<topic>/review.md` 中的单次复习 |
